### 🔥 #2｜FastRoverVLA: Fast Vision-Language-Action Execution for Off-Road Autonomous Driving

**Changtao Zhao, Yingxue Guan, Li Wang 等 (8 位作者)** |  `BJTU, BIT`

📎 [2611.26242](https://arxiv.org/abs/2611.26242) | `cs.RO cs.AI`

🎯 **Robotics / VLA Architecture** · 综合分 `6.66`

> Off-road vision-language-action (VLA) models generate scene-conditioned plans, but frequent trajectory updates can repeatedly invoke expensive multimodal inference. Reusing a prediction reduces this demand while leaving its commands exposed to changes in vehicle motion. FastRoverVLA addresses this mismatch by decoupling visual plan generation from motion-conditioned execution. Its training-free interface maintains decoded plans between visual predictions. 📎 [2611.25529](https://arxiv.org/abs/2611.25529) | `cs.RO cs.AI`

> Generalist robot policies execute atomic skills reliably but fail when the same skills are composed into long-horizon tasks. 📎 [2611.26385](https://arxiv.org/abs/2611.26385) | `cs.RO`

🎯 **General / Efficient Inference** · 综合分 `7.43`

> Prior work calls the high attention on the first and last action tokens of a flow-based VLA policy a radial action sink, and uses these tokens to set the execution horizon. In language models, a sink is a token with high incoming attention, a small value, and little effect on the output. We test whether that profile holds, not the horizon rule, in one $π_{0.5}$ checkpoint on five RoboCasa tasks.
