### 🔥 #1｜Embodied Turing Machines: Stateful Code for Robot Recursive Self-Improvement

**Kairui Hu, Siyuan Hu, Fangzhou Hong 等 (5 位作者)** |  `NTU`

📎 [2610.12369](https://arxiv.org/abs/2610.12369) | `cs.RO cs.CV`

> Most robot policies keep a model in the control loop: a VLA maps observations to actions, and an Agent Harness, such as Agent-as-Policy or Harness VLA queries a VLM for decision making at run time. We propose a different view: the embodied world is an Embodied Turing Machine, whose tape is the robot and environment state and rules are the policy. If this state can be represented accurately, the decision making can be written entirely in code. We therefore propose Code-Only-as-Policy (COAP): code measures and tracks the robot, environment, and task state from camera images and proprioception, and makes every decision from it. The same code applies across episodes, and different tasks share one library without a VLM or VLA in the loop
>
> **关键技术：** 递归自我改进 (RSI) / VLA

### 🔥 #3｜RoboRSI: Stable, efficient, and reusable robot self-evolution in complex real-world environments

**Zimo Wen, Yijin Chen, Yuxuan Cao 等 (11 位作者)**

📎 [2610.12424](https://arxiv.org/abs/2610.12424) | `cs.RO cs.AI`

> A generalist robot should not only perform diverse tasks but also improve through experience, turning what it learns during execution into capabilities that later tasks can reuse. We introduce RoboRSI, a robot self-improvement system built on Top-Down Skill Refinement (TSR). TSR decomposes tasks into compound, atomic, and base skills with scoped responsibilities and explicit input--output contracts, attributes each execution outcome to the responsible branch, and confines revision to that branch. On a mobile manipulator, RoboRSI develops multi-object household cleanup over 104 rounds. In simulation, it achieves the highest success rate on LIBERO, LIBERO-PRO, LIBERO-Plus, and RoboTwin, exceeding the strongest baseline by 2.7 to 11.0 percentage points

### 🔥 #7｜REACT: Rolling Denoising and Dual Decoupling for Reactive Robot Control with VLA Models

**Houlong Xiong, Zhenqi Qiu, Zechen Wang 等 (11 位作者)** |  `SJTU, ZJU, NUS`

📎 [2610.12007](https://arxiv.org/abs/2610.12007) | `cs.RO cs.AI`

> Flow-based vision-language-action (VLA) models generate action chunks for temporally coherent robot motion, but chunked control creates a fundamental closed-loop trade-off: long chunks provide smooth execution, whereas frequent replanning improves reactivity at the cost of action discontinuities. We introduce REACT, a rolling-denoising framework that makes flow-based VLAs more reactive while preserving long-horizon context. Instead of regenerating entire action chunks from scratch, REACT maintains a persistent action buffer with staggered flow timesteps. ### 🔥 #8｜PathTime-VLA: Path-Time Decoupling for Factorized Post-Training of Vision-Language-Action Policies

### 🔥 #9｜Residual Modeling Closes the Regression and Generative Policy Gap in Robot Learning

**Yuchen Zhou, Jiacheng You, Weikang Wan 等 (6 位作者)** |  `UCSD, UPenn, Tsinghua`

📎 [2610.12231](https://arxiv.org/abs/2610.12231) | `cs.RO`

> We revisit this gap from the perspective of statistical modeling: how action-prediction residuals shape policy optimization.
